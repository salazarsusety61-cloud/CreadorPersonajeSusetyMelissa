# Creador de Personaje — Guardianes del Talamanca

## Autora
Susety Melissa Rodríguez Salazar

## Universo
Mundo de fantasía inspirado en la naturaleza de Costa Rica, donde guardianes protegen las tierras sagradas.

## Clases
| Clase base | Nombre en el juego |
|---|---|
| Guerrero | Guardián del Volcán |
| Mago | Sabio de la Bruma |
| Arquero | Centinela del Bosque |
| Sanador | Custodio de las Aguas |

## Mejora propia
- Se agregó validación para que no se puedan crear personajes sin haber repartido todos los puntos.
- La ventana de Reglas muestra toda la información de forma clara.
- Los botones tienen mensajes de confirmación.

## Imágenes
- Imágenes sacadas de bancos gratuitos de internet.

## Uso de Inteligencia Artificial
- Se usó para consultar dudas de sintaxis y entender mejor conceptos de programación.
- Todo el código fue comprendido y escrito por nosotras.
